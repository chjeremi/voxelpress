Panduan Langkah Pembuatan

Pilih nama AI di bawah ini untuk melihat petunjuk lengkap ekspor file 3D `.STL` / `.OBJ`:

Langkah Membuat di Tripo3D ▾
  • Buka platform tripo3d.ai dan lakukan *sign in*.
  • Ketik deskripsi produk pada kotak pencarian (Contoh: "Minimalist Borobudur souvenir, solid base").
  • Tunggu proses pembuatan 3D selesai (sekitar 10–30 detik).
  • Klik tombol Download/Export pada hasil yang paling sesuai.
  • Pilih format file .STL atau .OBJ.
Langkah Membuat di Luma Genie ▾
  • Buka situs lumalabs.ai/genie.
  • Masukkan *prompt* bentuk cenderamata yang diinginkan pada kolom input.
  • Pilih salah satu dari 4 variasi model 3D yang dihasilkan.
  • Klik tombol Export 3D Model.
  • Unduh berkas dalam format .OBJ.
Langkah Membuat di Meshy AI ▾
  • Akses dashboard di meshy.ai dan pilih menu Text to 3D.
  • Masukkan *prompt* deskriptif dan pilih gaya visual (*Art Style*).
  • Klik tombol Generate dan tunggu model 3D terbentuk.
  • Pilih menu Download di pojok kanan atas.
  • Pilih format **.STL** atau **.OBJ** dengan opsi kepadatan *mesh* tinggi.
Langkah Membuat di CSM AI ▾
  • Masuk ke platform 3d.csm.ai.
  • Unggah sketsa gambar atau ketik instruksi teks produk kamu.
  • Jalankan proses *Generate Geometry*.
  • Setelah hasil 3D siap, klik tombol Export Asset.
  • Simpan file dalam format **.OBJ** ke komputer milikmu.
